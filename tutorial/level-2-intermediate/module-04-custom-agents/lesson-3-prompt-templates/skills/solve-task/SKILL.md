# Solve Task Skill

When solving a programming task:

1. **Understand** the requirements fully before writing code
2. **Plan** your approach -- break complex tasks into steps
3. **Implement** the solution with clean, readable code
4. **Test** your solution by running it
5. **Verify** the output matches expectations

## Code Quality Standards

- Use meaningful variable names
- Add comments for non-obvious logic
- Handle errors explicitly
- Follow the language's conventions
