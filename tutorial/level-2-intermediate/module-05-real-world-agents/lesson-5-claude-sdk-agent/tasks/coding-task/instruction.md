Create a Python script at /app/word_counter.py that:

1. Reads a text file from /app/sample.txt
2. Counts the number of words in the file
3. Counts the number of unique words (case-insensitive)
4. Writes a report to /app/report.txt with exactly this format:
   Total words: <count>
   Unique words: <count>

Then run the script to produce /app/report.txt.
