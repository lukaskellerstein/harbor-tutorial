Create a Python script at /app/fibonacci.py that defines a function called
fibonacci(n) which returns the n-th Fibonacci number (0-indexed, so fibonacci(0)=0,
fibonacci(1)=1, fibonacci(2)=1, fibonacci(3)=2, etc.).

Then run the script with an argument to verify it works:
  python3 /app/fibonacci.py 10

The output should print "55" (the 10th Fibonacci number).
