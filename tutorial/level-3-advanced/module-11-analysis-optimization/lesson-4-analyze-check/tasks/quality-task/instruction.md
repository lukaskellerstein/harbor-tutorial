Create a Python script at `/home/user/calculator.py` that implements a simple command-line calculator.

The script should:
1. Read an expression from `/home/user/expression.txt` (e.g., "3 + 5")
2. Support four operations: +, -, *, /
3. Handle integer and float operands
4. Print the result to stdout as a number
5. If division by zero is attempted, print "error: division by zero"
6. If the expression is malformed, print "error: invalid expression"
